03 / Problem Statement Challenges Identified

The Household Financial Management Dilemma

Why traditional informal expense tracking fails in shared and family households

📉 Unorganized Expense Logging

Households rely on paper slips, fragmented WhatsApp chats, or mental notes. Transactions lack structured categorization, leading to untraceable month-end cash leaks.

⏰ Missed Utility Bill Deadlines

Electricity, broadband, piped gas, and staff salaries have varying due dates. Without automated countdown alerts, late payment surcharges are routinely incurred.

👥 Ambiguous Family Cost Splitting

When family members or co-living roommates contribute to shared provisions, determining who paid what and calculating proportional spending shares creates friction.

🚫 Lack of Real-Time Health Metrics

Bank passbooks show past debit records but provide no category budget ceilings, visual charts, or early warning triggers before a category limit is breached.

06 / Proposed Solution The HomeLedger Pro Architecture

Unified Household Financial Intelligence

An integrated, single-page application combining ledger, bills, envelopes, and analytics

⚡ Fast, Lightweight & Client-Side

Engineered using React 18 and Vite. State is managed via the React Context API with immediate persistence to browser localStorage, ensuring zero server lag and instant offline availability.

🎯 Proactive Rather Than Passive

Computes a live financial health score (0–100) and triggers automated rule-based Smart Advisor alerts (danger, warning, success, info) when categories approach or exceed budget limits.

🏠 Built Specifically for the Household Unit

Utility bills (electricity, WiFi, water) and recurring domestic expenses are tied directly to members, giving complete transparency over who contributes what each month.

🔒 Zero Compromise Privacy & Control

Personal data never leaves the user's browser without explicit export. Only the designated administrator email can unlock user audit logs and management controls.

07 / System Architecture Data Flow & Hierarchy

System Architecture & Component Flow

High-level declarative view of components, providers, and state lifecycle

[USER CLIENT BROWSER]
├── Presentation Layer: App.jsx ➔ Navbar ➔ Views (Dashboard | Expenses | Budgets | Bills | Family | Admin)
├── State Management Layer (React Context API):
│ ├── AuthContext.jsx: User Sessions, Role Guards, Login/Signup, 3-Step Password Reset, Audit Logs
│ └── BudgetContext.jsx: Transactions, 15 Categories, Recurring Bills, Members, Health Metrics
├── Data Visualizations: Chart.js 4 (Doughnut Category Chart, Daily Line Chart, Budget Bar Chart)
└── Local Persistence: Web Storage API (localStorage: homeledger_pro_v1, homeledger_all_users_v2)
Unidirectional Flow

Actions dispatch into Context, state updates reactively, recalculating all metrics and triggering auto-rerenders.

State Guards

Unauthenticated traffic is caught by session guards; non-admins attempting admin tabs are auto-routed to dashboard.

Zero Backend Dependency

Completely self-contained. No external database or API keys required to execute the full functional suite.
